Files the site loads from this folder (replace them with your own; keep the names):
  photo.jpg (or photo.png)  - profile photo. Square, at least 400x400 px, ideally under 150 KB.
                              If neither exists, the page shows your initials.
  favicon.svg               - browser tab icon (also favicon-32.png and apple-touch-icon.png, 180x180).
  icons/github.svg|png, icons/linkedin.svg|png, icons/orcid.svg|png
                            - optional official icons for the link buttons. SVG is tried first,
                              then PNG; if neither exists, the generic icon is shown.
